## Purpose

Use this file as the default competency framework across companies. If a company specific model exists, use that model first and use this file as the fallback.

## Model Selection Order

1. Check coaching state for a company specific competency model path.
2. If present and relevant to the active company, load that model first.
3. If absent, use this general framework.
4. If multiple active companies exist, use the model for the company tied to the active command.

## Universal Competency Model

Use these as the baseline for JD mapping and question prediction.

| Competency | What Strong Looks Like | Typical Signals In JDs |
|---|---|---|
| Strategic Judgment | Chooses direction under ambiguity with clear tradeoffs | Own strategy, prioritize bets, roadmap decisions |
| Execution Rigor | Ships outcomes through disciplined planning and follow-through | Deliver end to end, drive execution, operational excellence |
| Cross Functional Influence | Aligns stakeholders without formal authority | Partner across teams, influence leaders, matrix navigation |
| Customer and Market Orientation | Grounds decisions in user and market evidence | Customer insights, user research, market analysis |
| Analytical Decision Making | Frames problems with data and measurable logic | Metrics, experimentation, KPI ownership, analytics |
| Communication and Narrative | Explains complex decisions clearly for different audiences | Executive communication, storytelling, synthesis |
| Leadership and Team Development | Raises team capability and decision quality | Mentoring, coaching, building high performing teams |
| Adaptability and Learning Velocity | Learns quickly in changing environments | Ambiguity, rapid change, iterate, growth mindset |
| Ownership and Accountability | Takes responsibility for outcomes and corrections | Own outcomes, accountable, bias for action |
| Risk and Governance Judgment | Balances speed with quality, compliance, and risk | Governance, controls, quality bar, security/privacy |

## Competency Extraction Rules

1. Extract the top 5 to 7 competencies from the JD in priority order.
2. Mark each competency as Screening or Differentiating.
3. Add confidence labels for interpretation quality.
4. Prefer explicit role verbs over vague descriptors.
5. Use repetition and ordering in JD sections as priority signals.

## Company Overlay Guidance

When creating a company overlay file under docs:

1. Keep a small map from company competencies to this universal model.
2. Note what is unique in interview style or scoring for that company.
3. Include question archetypes and anti patterns observed from real loops.
4. Add last updated date and evidence source quality.

## Output Contract For Commands

Commands using this file should output:

1. Top competencies in priority order.
2. Candidate evidence coverage by competency.
3. Gap type per competency: Frameable, Structural, or Unknown.
4. Recommended question themes tied to top competencies.

## Notes

Use this model to stay transferable across companies. Keep company specificity in overlays so the core framework remains stable and reusable.

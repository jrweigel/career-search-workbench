## Usage

Copy this file to `applications/tracker.md` to initialize pipeline tracking.

## Required Fields

Each active row should include:

* Company
* Role
* Stage
* Next Action
* Due Date
* Last Update
* Notes

## Stage Values

Use one of:

* Researching
* Applied
* Interviewing
* Offer
* Closed

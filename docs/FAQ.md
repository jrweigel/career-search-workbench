## Why does the coach not recognize a command

Open `SKILL.md` and confirm the command exists in the Command Registry.

## What should I run first

Run `kickoff`.

## When should I run map-jd

Run it after you have a specific JD and before editing your resume.

## When should I run check-consistency

Run it after updates to resume, LinkedIn, or pitch.

## Do I need all docs files to use the core coach

No. Core command behavior is defined in `SKILL.md` and `references/`.

## What if tracker files are missing

Run `status` and create tracker artifacts as prompted.

## Can I use this without sharing personal data

Yes. Keep personal artifacts local and use templates for public or team sharing.

## How do I adapt this for a different domain

Start with `references/interview-competencies.md` and adjust role patterns through `decode`, `prep`, and `practice`.

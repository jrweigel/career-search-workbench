## I Need To Decide Which Role To Pursue

Use `decode`.

## I Need To Target One JD Quickly

Use `map-jd` then `resume`.

## I Updated Resume or LinkedIn and Need Alignment Check

Use `check-consistency`.

## I Have an Interview Coming Up

Use `prep [company]`, then `concerns`, then `hype`.

## I Need Better Answers Under Pressure

Use `practice` and `mock [format]`.

## I Need To Analyze What Went Wrong

Use `analyze`, then `progress`.

## I Need Better Positioning Across Surfaces

Use `pitch`, then `resume`, then `linkedin`, then `check-consistency`.

## I Need Networking Motion

Use `network` then `outreach`.

## I Need Pipeline Visibility

Use `status`.

## I Have Recruiter Feedback or an Outcome

Use `feedback`.

## I Need A Fast Recruiter Screen Gate

Use this 6-step gate before going deeper:

1. Confirm compensation band and flexibility in the first call.
2. Confirm reporting line and decision-rights model.
3. Confirm whether the mandate is internal transformation, product AI, or both.
4. Confirm support model: direct team, dotted-line resources, and sponsor strength.
5. If the compensation gap is larger than about 25 percent at screen stage, re-scope quickly or close.
6. If fit is strong but the package is not, close quickly and preserve the relationship.

Then run `status` and update your application tracker the same day.
